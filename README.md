# Time-Series Forecasting and Generative Modeling

Academic deep-learning coursework consisting of three notebook-based experiments: stock-price time-series forecasting and image reconstruction/generation workflows.

## Contents

- `2802403776_Winston_UASDLNO1.ipynb`
- `2802403776_Winston_UASDLNO2.ipynb`
- `2802403776_Winston_UASDLNO3.ipynb`

The notebooks retain the original experiment code, visualisations, and outputs for academic review.

## Notes

- This repository is source-only. Original datasets, assignment brief, rendered PDF reports, and any generated local artefacts are intentionally excluded.
- Stock-data experiments are educational and are not financial advice or a trading system.
- Results depend on the local data, software versions, and hardware environment used when the notebooks were run.

## Requirements

Open the notebooks in Jupyter and install the libraries imported in each notebook. To reproduce data-dependent cells, obtain the original authorised datasets separately and keep them outside version control.
